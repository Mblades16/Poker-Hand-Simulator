# Poker Hand Simulator

## Description

This project is a C program that simulates dealing a five-card poker hand from a standard 52-card deck. The program creates the deck, randomly shuffles the cards, and deals five unique cards to the player.

## Features

- Creates a standard 52-card deck
- Uses structures to represent cards
- Randomly shuffles the deck
- Deals a five-card hand
- Tracks whether cards have been dealt
- Displays each card's value and suit

## Concepts Used

- C programming
- Structures
- Arrays
- Functions
- Function prototypes
- Loops
- Conditional statements
- Pointers
- Random number generation
- String manipulation

## Example Output

Your Poker Hand:

Ace of Spades  
7 of Hearts  
Queen of Clubs  
3 of Diamonds  
10 of Spades

The cards will be different each time the program runs because the deck is randomly shuffled.
